# Решение проблем - Dinov AI Tools

## 🔴 Ошибка: "Ollama недоступна по адресу http://localhost:11434"

### Причина
Ollama не запущена или работает на другом порту.

### Решение

**Шаг 1**: Проверьте, установлена ли Ollama
```bash
ollama --version
```

Если команда не найдена:
- Linux: `curl -fsSL https://ollama.ai/install.sh | sh`
- macOS: `brew install ollama` или скачать с https://ollama.ai
- Windows: скачать установщик с https://ollama.ai

**Шаг 2**: Запустите Ollama
```bash
ollama serve
```

Оставьте этот терминал открытым! Ollama должна работать постоянно.

**Шаг 3**: В НОВОМ терминале проверьте работу
```bash
curl http://localhost:11434/
```

Должно вернуть: `Ollama is running`

**Шаг 4**: Запустите приложение в третьем терминале
```bash
python main.py
```

## 🔴 Ошибка: "404 Not Found for url: .../api/chat"

### Причина
У вас старая версия Ollama, которая не поддерживает Chat API.

### Решение

**Вариант 1**: Обновите Ollama (рекомендуется)
```bash
# Linux/macOS
curl -fsSL https://ollama.ai/install.sh | sh

# Windows: скачайте новый установщик
```

**Вариант 2**: Ничего не делайте
Приложение автоматически переключится на старый API (`/api/generate`). Всё будет работать!

## 🔴 Ошибка: "Модель 'llama2' не найдена"

### Причина
Модель не загружена.

### Решение

**Шаг 1**: Проверьте доступные модели
```bash
ollama list
```

**Шаг 2**: Загрузите модель
```bash
# Базовая модель (рекомендуется)
ollama pull llama2

# Или более качественная
ollama pull mistral

# Для русского языка
ollama pull saiga
```

**Шаг 3**: Проверьте, что модель появилась
```bash
ollama list
```

**Шаг 4**: В приложении
1. Откройте вкладку "Настройки"
2. Нажмите "Обновить список моделей"
3. Выберите загруженную модель
4. Нажмите "Сохранить настройки"

## 🔴 Генерация очень медленная (минуты ожидания)

### Причины и решения

#### 1. Слабый процессор / мало памяти
**Решение**: Используйте более лёгкую модель
```bash
# Лёгкая модель (~2GB)
ollama pull phi

# Или tiny модель
ollama pull tinyllama
```

В настройках приложения выберите эту модель.

#### 2. Модель работает на CPU вместо GPU

**Для NVIDIA GPU**:
```bash
# Проверьте, видит ли Ollama GPU
nvidia-smi
```

Если GPU не используется, переустановите Ollama с поддержкой CUDA.

#### 3. Другие программы нагружают систему
**Решение**: Закройте браузеры, редакторы и т.д.

## 🔴 Ответы AI на английском, хотя я пишу по-русски

### Решение

**Шаг 1**: В приложении откройте "Настройки"

**Шаг 2**: В поле "Общий стиль генерации" напишите:
```
Отвечай ВСЕГДА на русском языке. Используй средневековый фэнтезийный стиль 
с высокопарной речью. Избегай современных слов и сленга. Если получаешь 
вопрос на русском - отвечай на русском.
```

**Шаг 3**: Нажмите "Сохранить настройки"

**Шаг 4**: В каждом персонаже в поле "Стиль речи" добавьте:
```
Говорит только на русском языке, [остальное описание стиля]
```

**Альтернатива**: Используйте модель с лучшей поддержкой русского:
```bash
ollama pull saiga  # Модель, обученная на русском
```

## 🔴 Приложение зависает при нажатии "Сгенерировать"

### Это нормально!

Генерация происходит в фоновом потоке. Первая генерация после запуска приложения может занять **30-60 секунд** (модель загружается в память).

### Что происходит:
1. Приложение отправляет запрос в Ollama
2. Ollama загружает модель в память (первый раз)
3. Ollama генерирует текст (10-30 сек)
4. Ответ появляется в приложении

### Если действительно зависло (прошло >2 минут):
1. Проверьте терминал Ollama - там будут логи
2. Закройте приложение и попробуйте снова
3. Используйте более лёгкую модель

## 🔴 ModuleNotFoundError: No module named 'PyQt5'

### Решение

```bash
pip install PyQt5 requests

# Если не работает, создайте виртуальное окружение
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows

pip install -r requirements.txt
```

## 🔴 "externally-managed-environment" при установке пакетов

### Решение

**Вариант 1**: Используйте виртуальное окружение (рекомендуется)
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

**Вариант 2**: Системная установка (не рекомендуется)
```bash
pip install --break-system-packages -r requirements.txt
```

**Вариант 3**: Через apt (только Ubuntu/Debian)
```bash
sudo apt install python3-pyqt5 python3-requests
```

## 🔴 Ollama использует слишком много памяти

### Решение

**Вариант 1**: Ограничьте память для Ollama
```bash
# Linux/macOS
export OLLAMA_MAX_LOADED_MODELS=1
ollama serve
```

**Вариант 2**: Используйте более лёгкую модель
```bash
ollama pull phi        # ~2GB
ollama pull tinyllama  # ~600MB
```

**Вариант 3**: Выгружайте модель после использования
```bash
# В отдельном терминале после работы
curl http://localhost:11434/api/generate -d '{"model": "llama2", "keep_alive": 0}'
```

## 🔴 Как использовать своё API (не Ollama)?

Приложение предназначено для работы с Ollama. Для других API (OpenAI, Claude и т.д.) потребуется модификация кода.

### Минимальная модификация:

Отредактируйте `modules/ollama_client.py`, заменив URL и формат запросов на нужный API.

Или создайте issue в репозитории с просьбой о поддержке другого API.

## 🔴 Приложение не видит изменения в лоре при генерации

### Решение

После изменения лора нажмите **"Сохранить изменения"**. Только после этого новый лор будет использоваться для генерации.

---

## 🔴 Диалоги не сохраняются / история не отображается

### Причина
Забыли нажать "Сохранить диалог" после генерации.

### Решение

После генерации ответа:
1. Проверьте, что ответ вас устраивает (можете отредактировать)
2. Нажмите "Сохранить диалог"
3. Только после этого диалог попадёт в историю
