# 🪄 AI Helper — Офлайн‑редактор текста с ролевыми и писательскими функциями

Мощный оффлайн инструмент для работы с текстом на базе локального ИИ (Ollama).

## 🎯 Возможности

- **Быстрый ИИ-редактор** — преобразование текста по стилю (Alt+W)
- **Главное меню** — доступ ко всем функциям (Alt+F)
- **Менеджер стилей** — создание и настройка стилей письма
- **База персонажей** — управление персонажами для историй
- **Генератор квестов** — автоматическое создание квестов и сюжетов
- **Редактор книг** — работа с книгами и главами
- **Чат-редактор** — работа с длинными текстами
- **Ролевая игра** — интерактивное общение с ИИ-персонажами

## 🌐 Технологии

- **Язык:** Go 1.22+
- **UI:** Fyne (современный кроссплатформенный UI)
- **ИИ:** Ollama (локальная LLM)
- **БД:** SQLite (файловая база данных)
- **Модель:** deepseek-v3.1:671b-cloud

## 🚀 Быстрый старт

### Требования

1. **Go 1.22+** установлен
2. **Ollama** установлен и запущен локально
3. Модель **deepseek-v3.1:671b-cloud** загружена в Ollama

### Установка Ollama

```bash
# Установите Ollama с официального сайта: https://ollama.ai
# Скачайте модель:
ollama pull deepseek-v3.1:671b-cloud
```

### Сборка

```bash
# Клонируйте репозиторий
git clone <repo-url>
cd aihelper

# Скачайте зависимости
go mod download

# Соберите приложение
go build -o aihelper cmd/aihelper/main.go

# Запустите
./aihelper
```

### Сборка для Windows

```bash
# На Linux/Mac для сборки Windows .exe:
GOOS=windows GOARCH=amd64 go build -o aihelper.exe cmd/aihelper/main.go
```

## 🗂️ Базы данных

Все данные хранятся локально в директории:
- **Windows:** `%APPDATA%/AIHelper/data/`
- **Linux/Mac:** `~/.config/AIHelper/`

### Структура баз:

- `characters.db` — персонажи и связи
- `quests.db` — квесты и этапы
- `books.db` — книги и страницы
- `styles.db` — стили текста
- `roleplay_sessions.db` — ролевые сессии
- `history.db` — история операций

## ⚙️ Настройка

Для изменения модели Ollama или адреса API, отредактируйте файл `cmd/aihelper/main.go`:

```go
ollamaClient := ollama.NewClient("http://127.0.0.1:11434", "deepseek-v3.1:671b-cloud")
```
