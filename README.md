# World Builder with Ollama

Десктопное приложение на Python (PyQt5) для создания и ведения ролевых миров с локальной интеграцией Ollama.

## Возможности

- **Редактор данных мира**: вкладки для лора, персонажей, сцен, ивентов, шаблонов и квестов. Поддерживаются CRUD-операции, импорта/экспорта.
- **Ассистент генерации**: кнопки "✨ Сгенерировать" рядом с полями позволяют с помощью модели Ollama заполнить атрибуты сущностей.
- **Система памяти**: семантическая и эпизодическая память на базе SQLite и векторных представлений, рабочая память сцен.
- **Групповые диалоги**: создание сцен с несколькими персонажами, генерация нескольких вариантов реплик, редактирование и продолжение диалога.
- **Генератор квестов**: создание квестов и событий на основе имеющегося лора.
- **Интерактивная карта связей**: граф связей персонажей и событий.
- **Экспорт**: Markdown и PDF.
- **Дайс-роллер**: встроенный генератор бросков.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```
