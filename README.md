# 🏰 Medieval RPG Telegram Bot

Полноценная средневековая RPG-игра для Telegram с системой валют, королевствами, казино и путешествиями.

## 🎮 Особенности

### Игровые системы
- **4 расы**: Люди, Эльфы, Дварфы, Орки
- **4 класса**: Воин, Маг, Лучник, Жрец
- **4 королевства**: Каждая раса привязана к своему королевству
- **4-уровневая валютная система**: Медь, Серебро, Золото, Платина

### Валютная система
```
🟤 100 медных = ⚪ 1 серебряная
⚪ 100 серебряных = 🟡 1 золотая
🟡 100 золотых = 💎 1 платиновая
```

### Зал Удачи (Казино)
6 уникальных игр:
1. 🎯 **Метание топоров** - попади в центр мишени
2. 🎲 **Кости Судьбы** - собери комбинацию из трёх кубиков
3. 🃏 **Рыцарский покер** - средневековая версия покера
4. 🏹 **Стрельба по мишеням** - попади в движущиеся цели
5. ⚔️ **Гладиаторская рулетка** - ставки на исход боя
6. 🔮 **Гадание на рунах** - древнее предсказание судьбы

### Королевства
- 🏰 **Валхейм** (Люди) - центр торговли и рыцарства
- 🌲 **Сильвания** (Эльфы) - магические леса
- ⛰️ **Казад-Дум** (Дварфы) - горные кузницы
- ⚔️ **Кхан-Гор** (Орки) - суровые степи

## 🚀 Установка

### Требования
- Python 3.10+
- pip

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone <repository_url>
cd medieval_rpg_bot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте конфигурацию в `medieval_bot/config.py`:
```python
BOT_TOKEN = "your_telegram_bot_token"
```

4. Запустите бота:
```bash
python -m medieval_bot.bot
```

## 🎲 Игровой процесс

### Регистрация
1. Отправьте `/start` боту
2. Введите имя персонажа
3. Выберите расу (определит ваше королевство)
4. Выберите класс
5. Получите стартовый капитал: 🟤 500 медных монет

### Основное меню
- 🏰 **Королевство** - исследуй своё королевство
- 👤 **Профиль** - просмотр характеристик
- 🎒 **Инвентарь** - управление предметами
- 🗺️ **Путешествия** - перемещение между королевствами
- 🏪 **Магазин** - покупка снаряжения
- 🎲 **Зал Удачи** - казино с 6 играми

### Система валют
Используйте **💱 Обменную лавку** для конвертации:
- Обмен на более ценную валюту (100 к 1)
- Размен на мелочь
- Просмотр курсов обмена

## 🎰 Казино - Подробности

### Влияние характеристик
- 🍀 **Удача** - повышает шансы в метании топоров
- 🏃 **Ловкость** - улучшает меткость в стрельбе

### Лимиты ставок
- 🟤 Медь: 1-99 монет
- ⚪ Серебро: 1-99 монет
- 🟡 Золото: 1-99 монет
- 💎 Платина: 1-10 монет

### Множители выигрыша

**Метание топоров:**
- 🎯 Яблочко: x5
- 🟡 Внутренний круг: x3
- 🟠 Средний круг: x2
- 🔴 Внешний круг: x1.5

**Кости Судьбы:**
- 🎲🎲🎲 Три одинаковых: x10
- 🎲🎲 Два одинаковых: x3
- 📊 Стрит: x5
- 🔥 Сумма 15+: x2

**Рыцарский покер:**
- 🏆 Роял-флеш: x100
- ⚡ Стрит-флеш: x50
- 🎰 Каре: x25
- 🏠 Фулл-хаус: x15
- И другие...

## 🛠️ Технологии

- **aiogram 3.x** - асинхронный фреймворк для Telegram Bot API
- **SQLAlchemy** - ORM для работы с базой данных
- **SQLite** - база данных (можно заменить на PostgreSQL)
- **asyncio** - асинхронное программирование

## 📊 База данных

Автоматически создаются следующие таблицы:
- `users` - игроки
- `stats` - характеристики персонажей
- `inventory` - инвентарь
- `kingdoms` - королевства
- `shops` - магазины
- `casino_stats` - статистика казино
- `achievements` - достижения
