# 🪄 AI Helper — Офлайн-редактор текста с ролевыми и писательскими функциями

Офлайн программа для Windows, которая позволяет работать с текстами через AI в любом приложении, управлять персонажами, генерировать квесты, книги и участвовать в ролевых играх.

## 🌟 Основные возможности

- **Быстрый редактор текста** по горячей клавише (Alt+W) — работает в любом приложении
- **Менеджер стилей** — создавайте и управляйте кастомными стилями написания
- **База персонажей** — храните и редактируйте характеры, цели, описания
- **Генератор квестов** — создавайте квесты на основе персонажей и шаблонов
- **Редактор книг** — разбивайте тексты на главы и страницы
- **Ролевая игра (Roleplay Engine)** — чат с AI-персонажами с памятью и настроением
- **История** — все взаимодействия сохраняются в локальную базу

## 🚦 Горячие клавиши

| Команда   | Действие                                                      |
|-----------|---------------------------------------------------------------|
| **Alt+W** | Быстрый редактор текста (выделить + трансформировать стиль)   |
| **Alt+F** | Главное меню (доступ ко всем функциям и базам)                |

## 📦 Установка и запуск

### Требования

- Python 3.10+
- [Ollama](https://ollama.ai/) установлен и запущен локально
- Модель `deepseek-v3.1:671b-cloud` загружена в Ollama

### Установка

```bash
# Клонируйте репозиторий
git clone <repository-url>
cd ai-helper

# Установите зависимости
pip install -e .
```

### Настройка Ollama

```bash
# Убедитесь, что Ollama запущен
ollama serve

# Загрузите модель (если ещё не загружена)
ollama pull deepseek-v3.1:671b-cloud
```

### Запуск

```bash
# Из командной строки
ai-helper

# Или прямо через Python
python -m ai_helper
```

## 🎨 Интерфейс

Приложение использует **Textual** — современный TUI (Terminal User Interface) фреймворк с красивым дизайном в стиле Fluent Design.

### Элементы интерфейса:

- **Левая панель** — навигация по модулям
- **Вкладки** — переключение между разными функциями
- **Тёмная тема** с фиолетовыми акцентами
- **Плавные тени и скругления**

## 📚 Модули приложения

### 1. Быстрый редактор (`Alt+W`)

Выделите текст в любом приложении, нажмите `Alt+W`:
- Введите стиль (средневековый, киберпанк, деловой, юмор и т.д.)
- Укажите возраст автора
- Добавьте дополнительный контекст
- AI переписывает текст в выбранном стиле

### 2. Менеджер стилей

- Создавайте собственные стили написания
- Определяйте правила в YAML формате
- Используйте стили в быстром редакторе

Пример стиля:
```yaml
tone: formal
vocabulary: professional
length: verbose
forbidden_words: ["слэнг", "разговорное"]
```

### 3. База персонажей

Управление персонажами для историй и ролевых игр:
- Имя, возраст, пол
- Черты характера
- Голос и стиль речи
- Цели и мотивация
- Биография

### 4. Генератор квестов

Создание квестов на основе:
- Жанра и сеттинга
- Сложности
- Персонажей из базы
- Синопсиса

AI генерирует:
- Структурированный квест в Markdown
- Диалоги NPC
- Цели игрока
- Варианты развязки
- Награды

### 5. Ролевая игра (Roleplay)

Интерактивный чат с AI-персонажами:
- Выберите персонажа из базы
- Задайте сеттинг
- Управляйте памятью и настроением персонажа
- Ведите диалог
- Редактируйте сообщения
- Сохраняйте сессии

Персонаж помнит:
- Предыдущие реплики
- Свои цели
- Настроение
- Контекст беседы

### 6. История

Просмотр всех взаимодействий с AI:
- Время запроса
- Исходный текст
- Результат
- Применённый стиль

## 🗂️ Структура баз данных

Все данные хранятся в SQLite в папке `~/.ai_helper/databases/`:

- `characters.db` — персонажи и их связи
- `quests.db` — квесты и их шаги
- `books.db` — книги и страницы
- `styles.db` — стили написания
- `roleplay.db` — сессии и диалоги
- `history.db` — история запросов

## 🔧 Конфигурация

Настройки можно изменить в `ai_helper/config.py`:

```python
OLLAMA_URL = "http://127.0.0.1:11434/api/chat"
OLLAMA_MODEL = "deepseek-v3.1:671b-cloud"
APP_DATA_DIR = Path.home() / ".ai_helper"
```

## 🎯 Примеры использования

### Быстрое преобразование текста

1. Запустите приложение
2. Нажмите `Alt+W` или перейдите в "Редактор"
3. Введите текст
4. Укажите стиль (например, "средневековый")
5. Нажмите "Переписать текст"

### Создание персонажа

1. Перейдите в "Персонажи"
2. Заполните поля (имя, возраст, черты)
3. Нажмите "Сохранить персонажа"

### Генерация квеста

1. Откройте "Квесты"
2. Укажите жанр и сложность
3. Выберите персонажей
4. Напишите синопсис
5. Нажмите "Сгенерировать"

### Ролевая игра

1. Перейдите в "Ролевая"
2. Введите имя персонажа
3. Задайте сеттинг и настроение
4. Начните диалог
