# Шахматы - Игра с ботом

Красивая веб-игра в шахматы с простым ботом, созданная на HTML, CSS и JavaScript.

## Особенности

- 🎨 **Красивый дизайн** - современный градиентный интерфейс с плавными анимациями
- 🤖 **Бот с 3 уровнями сложности** - от легкого до сложного
- ♟️ **Полная реализация правил шахмат** - все фигуры ходят по правилам
- 📜 **История ходов** - отслеживание всех сделанных ходов
- 🔄 **Отмена хода** - возможность отменить последний ход
- 🎯 **Подсветка возможных ходов** - зеленые круги показывают доступные клетки
- 📱 **Адаптивный дизайн** - работает на всех устройствах

## Как запустить

Просто откройте файл `index.html` в любом современном браузере.

Или запустите локальный сервер:

```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js (если установлен http-server)
npx http-server
```

Затем откройте http://localhost:8000 в браузере.

## Как играть

1. **Вы играете белыми** - первый ход за вами
2. **Выберите фигуру** - кликните на белую фигуру
3. **Сделайте ход** - кликните на зеленый круг (возможный ход)
4. **Бот ответит** - черные фигуры ходят автоматически

## Правила

- Все фигуры ходят по стандартным шахматным правилам
- Захват фигур происходит при ходе на занятую клетку
- Игра заканчивается при захвате короля
- Можно отменить ход кнопкой "Отменить ход"

## Сложность бота

- **Легкий** - бот делает случайные ходы
- **Средний** - бот предпочитает захватывать фигуры
- **Сложный** - бот оценивает ценность фигур и выбирает лучший ход

## Технологии
