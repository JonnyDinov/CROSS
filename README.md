# Dinov AI Tools

Настольное приложение для управления и генерации контента для ролевого сервера в стиле средневекового фэнтези, работающее с локальной моделью Ollama.

## Возможности

### 1. Управление лором
- Редактирование и сохранение лора мира
- Лор используется как контекст для всех генераций AI

### 2. Управление персонажами
- Создание, редактирование и удаление персонажей
- Параметры персонажа:
  - Имя
  - Характер
  - Стиль речи
  - Краткая история
  - Роль в мире

### 3. Квесты и события
- Создание квестов и событий с различными темами:
  - Политика, Война, Тайна, Быт, Мистика и другие
- Выбор стиля повествования:
  - Героический, Трагический, Сатирический и другие
- Генерация контента при помощи AI на основе лора
- Ручное редактирование сгенерированного контента

### 4. Диалоги
- Выбор персонажа для диалога
- Генерация ответов AI с учетом:
  - Характера персонажа
  - Стиля речи
  - Контекста мира (лора)
  - Истории предыдущих диалогов (опционально)
- Сохранение и просмотр истории диалогов
- Копирование ответов в буфер обмена

### 5. Настройки
- Настройка URL Ollama API (по умолчанию: http://localhost:11434)
- Выбор модели AI
- Настройка общего стиля генерации
- Включение/выключение сохранения контекста диалогов

## Установка

### Требования
- Python 3.7+
- Ollama (установленный локально)

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd dinov-ai-tools
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Установите и запустите Ollama:
```bash
# Скачайте и установите Ollama с https://ollama.ai
ollama pull llama2
# или другую модель по вашему выбору
```

## Запуск

```bash
python main.py
```

## База данных

Приложение использует SQLite для хранения всех данных:
- **lore** - содержимое лора
- **characters** - персонажи с их характеристиками
- **events** - квесты и события
- **dialogues** - история диалогов
- **settings** - настройки приложения

База данных создается автоматически при первом запуске в директории `data/`.

## Использование Ollama

Приложение работает с локальной моделью Ollama через REST API.

### Настройка Ollama:

1. Установите Ollama с официального сайта: https://ollama.ai
2. Загрузите модель:
```bash
ollama pull llama2
# или другие модели:
# ollama pull mistral
# ollama pull codellama
```

3. Запустите Ollama (обычно запускается автоматически как сервис)

4. В настройках приложения укажите:
   - URL API: `http://localhost:11434` (по умолчанию)
   - Модель: имя загруженной модели

### Рекомендуемые модели для ролевых игр:
- `llama2` - базовая модель, хороший баланс
- `mistral` - более качественная генерация
- `neural-chat` - специализируется на диалогах

## Функционал AI

### Генерация квестов
При нажатии "Сгенерировать при помощи ИИ" в квестах, AI:
1. Учитывает текущий лор мира
2. Использует выбранную тему и стиль
3. Применяет общий стиль генерации из настроек
4. Создает уникальный квест/событие

### Генерация диалогов
При генерации ответа персонажа, AI:
1. Использует контекст лора
2. Учитывает характер и стиль речи персонажа
3. Опционально использует историю предыдущих диалогов
4. Отвечает от лица выбранного персонажа

## Тёмная тема

Приложение использует минималистичную тёмную тему для комфортной работы.
