❓ ПРОБЛЕМЫ?

1. Ollama не подключается:
   • Запустите Ollama приложение
   • Или: ollama serve
   • Проверка: test_ollama.bat

2. Модель не найдена:
   • ollama list (посмотреть установленные)
   • ollama pull gpt-oss:120b-cloud (установить)

3. Ошибки в программе:
   • Смотрите логи: %LOCALAPPDATA%\WindowsAIAgent\logs\agent.log
   • Или в GUI: вкладка Logs

4. GUI не запускается:
   • pip install --upgrade PySide6
