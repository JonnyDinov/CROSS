## [1.0.0] - 2024-10-29

### 🎉 Initial Release

Первая полноценная версия Medieval RPG Telegram Bot!

### ✨ Added

#### Core Systems
- Регистрация персонажей с FSM
- Система из 4 рас (Люди, Эльфы, Дварфы, Орки)
- Система из 4 классов (Воин, Маг, Лучник, Жрец)
- Расчёт характеристик на основе расы и класса

#### Currency System
- 4-уровневая валютная система (Медь → Серебро → Золото → Платина)
- Курс обмена 100:1 между уровнями
- Автоматическая конвертация для отображения
- Хранение всей валюты в меди в БД

#### Kingdoms
- 4 королевства с уникальными описаниями
- Жёсткая привязка раса → королевство
- 9 локаций в каждом королевстве:
  - Центральная площадь
  - Тронный зал
  - Торговая улица
  - Арена
  - Таверна
  - Кузница
  - Библиотека
  - Обменная лавка
  - Зал Удачи

#### Casino System - "Зал Удачи"
6 полноценных игр:
1. 🎯 **Метание топоров** - зависит от характеристики "Удача"
2. 🎲 **Кости Судьбы** - 3 кубика с комбинациями
3. 🃏 **Рыцарский покер** - средневековый покер с уникальными мастями
4. 🏹 **Стрельба по мишеням** - зависит от "Ловкости"
5. ⚔️ **Гладиаторская рулетка** - ставки на цвет или ноль
6. 🔮 **Гадание на рунах** - 3 руны судьбы

Фичи казино:
- Выбор валюты для ставок (4 стола)
- Лимиты ставок по валютам
- Статистика игр (сыграно, выиграно, проиграно)
- Отслеживание самого крупного выигрыша
- Серии побед
- Честные алгоритмы генерации

#### Exchange System
- Обмен на более ценную валюту
- Размен на мелочь
- Отображение курсов обмена
- Детальный показ кошелька

#### Travel System
- Путешествия между всеми 4 королевствами
- Стоимость путешествия от 10 до 25 серебра
- Отслеживание текущей локации

#### Profile System
- Полный профиль персонажа
- Отображение всех характеристик
- Информация о кошельке
- Статистика казино
- Уровень и опыт (placeholder)

#### Shop System
- 5 категорий товаров:
  - Оружие
  - Броня
  - Зелья
  - Магия
  - Провиант
- Отображение ассортимента (placeholder для покупок)

#### Database
- 7 таблиц:
  - users (игроки)
  - stats (характеристики)
  - inventory (инвентарь)
  - kingdoms (королевства)
  - shops (магазины)
  - casino_stats (статистика казино)
  - achievements (достижения)
- Async SQLAlchemy
- Автоматическая инициализация
- SQLite (возможность переключения на PostgreSQL)

#### UI/UX
- InlineKeyboard для всех меню (15+ клавиатур)
- HTML форматирование текстов
- Эмодзи для всех элементов
- Средневековый стиль текстов
- Полная русская локализация

#### Documentation
- README.md - основная документация
- QUICKSTART.md - быстрый старт
- GAMES.md - описание всех игр
- DEVELOPMENT.md - руководство разработчика
- API.md - полное API Reference
- PROJECT_STATUS.md - статус проекта
- CHANGELOG.md - этот файл

#### Scripts
- run.py - скрипт запуска Python
- start.sh - bash-скрипт быстрого запуска
- test_db.py - тест базы данных

#### Configuration
- config.py - централизованная конфигурация
- requirements.txt - зависимости проекта
- .gitignore - правила игнорирования файлов

### 🔧 Technical Details

#### Dependencies
- aiogram 3.3.0 - async Telegram bot framework
- SQLAlchemy 2.0.23 - async ORM
- aiosqlite 0.19.0 - async SQLite driver
- redis 5.0.1 - кэширование (опционально)

#### Architecture
- Модульная структура
- Async/await throughout
- FSM для диалогов
- Separate handlers for each feature
- Utils для переиспользуемого кода

#### Code Quality
- ~2500+ строк кода
- 20+ Python файлов
- Structured и читаемый код
- Готов к расширению

### 🎯 Game Balance

#### Starting Values
- Стартовая валюта: 🟤 500 медных монет
- Базовые характеристики: 10 в каждой
- Стартовый уровень: 1

#### Race Bonuses
- Люди: сбалансированные (без бонусов)
- Эльфы: +2 ловкость, +1 интеллект, -1 выносливость
- Дварфы: +2 сила, +2 выносливость, -1 ловкость
- Орки: +3 сила, +1 выносливость, -1 интеллект

#### Class Bonuses
- Воин: +3 сила, +2 выносливость, +1 ловкость
- Маг: +4 интеллект, +1 ловкость
- Лучник: +4 ловкость, +1 сила, +1 интеллект
- Жрец: +3 интеллект, +2 выносливость

#### Casino Odds
Сбалансированные шансы для честной игры с возможностью влияния через характеристики.
