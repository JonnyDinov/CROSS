# 🔄 Changes Log - v1.1.0

## Улучшения UI/UX

### Главное изменение: ReplyKeyboard + InlineKeyboard
Разделили интерфейс на два уровня:
- **Основное меню** - обычные кнопки ReplyKeyboard (всегда видны)
- **Вложенные меню** - InlineKeyboard (для детального управления)

### Преимущества новой структуры:
✅ Быстрый доступ к основным разделам
✅ Кнопки всегда на экране
✅ Более интуитивный интерфейс
✅ Меньше кликов для базовых действий

## Рефакторинг структуры

### Создан файл constants.py
Вынесены все константы в отдельный файл:
- `RACE_TO_KINGDOM` - привязка рас к королевствам
- `RACE_BONUSES` - бонусы характеристик от рас
- `CLASS_BONUSES` - бонусы характеристик от классов
- `BASE_STATS` - базовые характеристики
- `TRAVEL_COSTS` - стоимость путешествий
- `CURRENCY_MULTIPLIERS` - множители валют
- `SHOP_ITEMS` - товары магазинов
- `SHOP_CATEGORIES` - названия категорий
- `RACE_DESCRIPTIONS` - описания рас
- `CLASS_DESCRIPTIONS` - описания классов
- `MessageCommands` - enum команд меню

### Создан модуль keyboards/reply.py
Клавиатуры для основного меню:
- `main_menu_keyboard()` - главное меню
- `remove_keyboard()` - удаление клавиатуры

### Создан handlers/menu.py
Централизованный обработчик основных команд:
- `handle_kingdom()` - Королевство
- `handle_profile()` - Профиль
- `handle_travel()` - Путешествия
- `handle_inventory()` - Инвентарь
- `handle_shop()` - Магазин
- `handle_quests()` - Квесты
- `handle_casino()` - Зал Удачи

## Оптимизация кода

### Удалены дублирующиеся обработчики
- Из `profile.py` - обработчики перенесены в `menu.py`
- Из `travel.py` - убрано дублирование меню

## Для разработчиков

### Как добавить новую кнопку в основное меню:

1. Добавить в `MessageCommands` (constants.py):
```python
NEW_SECTION = "🆕 Новый раздел"
```

2. Добавить кнопку в `main_menu_keyboard()` (keyboards/reply.py):
```python
KeyboardButton(text=MessageCommands.NEW_SECTION)
```

3. Создать обработчик в `handlers/menu.py`:
```python
@router.message(F.text == MessageCommands.NEW_SECTION)
async def handle_new_section(message: Message):
    # Your code here
```

### Как добавить новую расу:

1. Обновить `RACE_TO_KINGDOM` в constants.py
2. Добавить в `RACE_BONUSES`
3. Добавить в `RACE_DESCRIPTIONS`
4. Добавить кнопку в `race_selection_keyboard()`

Просто и понятно! 🎉
