# Руководство пользователя Dinov AI Tools

## Быстрый старт

### 1. Первый запуск

После запуска приложения вы увидите окно с пятью вкладками:
- **Лор** - управление описанием мира
- **Персонажи** - создание и редактирование персонажей
- **Квесты и события** - генерация и управление событиями
- **Диалоги** - создание диалогов с персонажами
- **Настройки** - конфигурация приложения

### 2. Настройка подключения к Ollama

Перейдите во вкладку **Настройки**:

1. Убедитесь, что Ollama запущена локально
2. Проверьте URL API (по умолчанию `http://localhost:11434`)
3. Нажмите "Обновить список моделей" - должны появиться доступные модели
4. Выберите нужную модель (например, `llama2` или `mistral`)
5. Установите общий стиль генерации (необязательно)
6. Включите "Сохранять контекст диалогов" для более связных разговоров
7. Нажмите "Сохранить настройки"

### 3. Создание лора

Перейдите во вкладку **Лор**:

1. В текстовом поле уже будет базовый текст
2. Отредактируйте его, добавив описание вашего мира:
   - География
   - История
   - Магическая система
   - Политическое устройство
   - Культура и традиции
3. Нажмите "Сохранить изменения"

**Важно**: Лор используется как контекст для всех генераций AI!

### 4. Создание персонажей

Перейдите во вкладку **Персонажи**:

1. Нажмите "Добавить"
2. Заполните поля:
   - **Имя**: Имя персонажа
   - **Характер**: Описание личности (например, "Мудрый и терпеливый старец")
   - **Стиль речи**: Как говорит персонаж (например, "Говорит высокопарно, цитирует древние тексты")
   - **История**: Краткая биография
   - **Роль в мире**: Положение в обществе (например, "Советник короля")
3. Нажмите "Сохранить"

Можно создать несколько персонажей. Их можно редактировать (кнопка "Редактировать") или удалять (кнопка "Удалить").

### 5. Генерация квестов и событий

Перейдите во вкладку **Квесты и события**:

#### Создание нового квеста:

1. Нажмите "Новое событие"
2. Заполните:
   - **Название**: Название квеста или события
   - **Тема**: Выберите из списка или введите свою (Война, Политика, Тайна и т.д.)
   - **Стиль повествования**: Героический, Трагический и т.д.
   - **Участники**: Отметьте персонажей, которые участвуют в событии
3. Либо напишите описание вручную, либо нажмите "Сгенерировать при помощи ИИ"
4. AI создаст подробное описание события с учетом:
   - Лора мира
   - Выбранных персонажей
   - Темы и стиля
5. Отредактируйте результат при необходимости
6. Нажмите "Сохранить"

### 6. Создание диалогов

Перейдите во вкладку **Диалоги**:

1. Выберите персонажа из выпадающего списка
2. В поле "История последних диалогов" будет показана история
3. Введите реплику игрока в поле "Реплика игрока"
4. Нажмите "Сгенерировать ответ ИИ"
5. AI создаст ответ персонажа с учетом:
   - Характера персонажа
   - Его стиля речи
   - Контекста мира
   - Предыдущих диалогов (если включено в настройках)
6. Можете отредактировать ответ вручную
7. Нажмите "Скопировать текст" для копирования в буфер обмена
8. Нажмите "Сохранить диалог" для сохранения в историю

## Примеры использования

### Пример 1: Создание квеста с политической интригой

**Лор:**
```
Королевство Валдория раздирается борьбой за власть между тремя домами...
```

**Персонаж 1:**
- Имя: Граф Эдмунд Черный
- Характер: Хитрый, амбициозный политик
- Стиль речи: Вежливый, но с подтекстом

**Квест:**
- Название: Тайный союз
- Тема: Политика
- Стиль: Драматический
- Участники: Граф Эдмунд Черный

AI сгенерирует подробное описание интриги с учетом всех параметров.

### Пример 2: Диалог с мудрецом

**Персонаж:**
- Имя: Мерлин Звездочёт
- Характер: Мудрый, но загадочный
- Стиль речи: Говорит загадками и метафорами

**Реплика игрока:**
"Мастер, что вы знаете о древнем пророчестве?"

AI создаст ответ в стиле персонажа, используя загадочную речь и ссылаясь на лор мира.

## Советы по работе

1. **Чем подробнее лор, тем лучше генерация** - уделите время описанию мира
2. **Детальные персонажи = живые диалоги** - подробно опишите характер и стиль речи
3. **Используйте контекст диалогов** - включите эту опцию для более связных разговоров
4. **Экспериментируйте со стилями** - разные стили повествования дают разные результаты
5. **Редактируйте результаты** - AI даёт основу, вы можете её улучшить
6. **Сохраняйте регулярно** - все изменения сохраняются в локальную базу

## Устранение проблем

### AI не отвечает / зависает

- Убедитесь, что Ollama запущена
- Проверьте URL в настройках
- Попробуйте перезапустить Ollama: `ollama serve`

### Модели не загружаются

```bash
# Загрузите модель вручную
ollama pull llama2
# или
ollama pull mistral
```

### Генерация слишком медленная

- Используйте более легкую модель (например, `llama2` вместо `llama2:70b`)
- Убедитесь, что на компьютере достаточно ресурсов
- Закройте другие ресурсоёмкие приложения

### Ответы AI не на русском языке

- В настройках укажите: "Общий стиль генерации: Отвечай всегда на русском языке в средневековом фэнтезийном стиле"
- Напишите лор на русском языке
- Используйте модели с поддержкой многоязычности (mistral, neural-chat)

## Горячие клавиши

Пока не реализованы, но планируются:
- `Ctrl+S` - быстрое сохранение
- `Ctrl+N` - создание нового элемента
- `Ctrl+Tab` - переключение между вкладками

## База данных

Все данные хранятся в файле `data/dinov_ai.db`.

Для резервного копирования просто скопируйте этот файл.

Для переноса на другой компьютер:
1. Скопируйте `data/dinov_ai.db`
2. Поместите в директорию `data/` нового приложения
3. Запустите приложение - все данные будут доступны
