# Быстрый старт - Dinov AI Tools

## 📋 Краткая инструкция для начала работы

### Шаг 1: Установка Ollama

#### 🐧 Linux
```bash
curl -fsSL https://ollama.ai/install.sh | sh
```

#### 🍎 macOS
```bash
brew install ollama
```
Или скачайте с https://ollama.ai/download/mac

#### 🪟 Windows
Скачайте установщик: https://ollama.ai/download/windows

---

### Шаг 2: Запуск Ollama

После установки Ollama обычно запускается автоматически. Если нет:

```bash
ollama serve
```

Оставьте этот терминал открытым! Ollama должна работать в фоне.

---

### Шаг 3: Загрузка модели

Откройте **НОВЫЙ** терминал и выполните:

```bash
# Рекомендуемая модель для начала (7B параметров, ~4GB)
ollama pull llama2

# Или более качественная модель (если есть память, ~4.1GB)
ollama pull mistral

# Для русского языка (экспериментально)
ollama pull saiga
```

Проверьте установленные модели:
```bash
ollama list
```

---

### Шаг 4: Проверка работы Ollama

Протестируйте в терминале:
```bash
ollama run llama2 "Say hello"
```

Если видите ответ модели - всё работает! ✅

---

### Шаг 5: Установка зависимостей приложения

```bash
# Создайте виртуальное окружение (рекомендуется)
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows

# Установите зависимости
pip install -r requirements.txt
```

---

### Шаг 6: Запуск приложения

```bash
python main.py
```

## 🎯 Первые действия в приложении

### 1. Настройте подключение

1. Откройте вкладку **"Настройки"** (последняя вкладка)
2. Проверьте URL: должен быть `http://localhost:11434`
3. Нажмите **"Обновить список моделей"**
4. Если модели появились - всё готово! ✅

### 2. Создайте лор мира

1. Откройте вкладку **"Лор"**
2. Напишите описание вашего мира, например:

```
Королевство Валдория - средневековое фэнтезийное государство, 
расположенное среди высоких гор. Здесь правит династия драконьих 
королей, а магия является частью повседневной жизни. 

Три великих дома борются за влияние при дворе: Дом Огня, 
Дом Льда и Дом Теней. Каждый дом владеет древними артефактами 
и тайными знаниями.
```

3. Нажмите **"Сохранить изменения"**

### 3. Создайте первого персонажа

1. Откройте вкладку **"Персонажи"**
2. Нажмите **"Добавить"**
3. Заполните:
   - **Имя**: Мерлин Звездочёт
   - **Характер**: Мудрый, загадочный, терпеливый учитель
   - **Стиль речи**: Говорит метафорами и загадками, цитирует древние тексты
   - **История**: Древний маг, хранитель знаний, живёт в башне на краю королевства
   - **Роль в мире**: Советник короля, хранитель древних знаний
4. Нажмите **"Сохранить"**

### 4. Попробуйте генерацию диалога

1. Откройте вкладку **"Диалоги"**
2. Выберите созданного персонажа
3. Напишите реплику, например: "Мастер, что вы знаете о древнем пророчестве?"
4. Нажмите **"Сгенерировать ответ ИИ"**
5. Подождите 10-30 секунд (зависит от мощности компьютера)
6. Получите ответ в стиле персонажа! 🎉

### 5. Создайте квест

1. Откройте вкладку **"Квесты и события"**
2. Нажмите **"Новое событие"**
3. Заполните:
   - **Название**: Тайна пропавшего артефакта
   - **Тема**: Тайна
   - **Стиль**: Драматический
   - Отметьте галочкой персонажа
4. Нажмите **"Сгенерировать при помощи ИИ"**
5. Получите готовый квест! ✨

## ❌ Решение проблем

### "Ollama недоступна по адресу..."

**Причина**: Ollama не запущена

**Решение**:
```bash
# Запустите в отдельном терминале
ollama serve
```

### "Модель 'llama2' не найдена"

**Причина**: Модель не загружена

**Решение**:
```bash
ollama pull llama2
```

### "404 Not Found for url: .../api/chat"

**Причина**: Старая версия Ollama без Chat API

**Решение**: 
- Приложение автоматически переключится на API generate
- Или обновите Ollama до последней версии

### Генерация очень медленная

**Причины и решения**:
- Используйте более лёгкую модель: `ollama pull phi`
- Закройте другие программы
- Проверьте, использует ли Ollama GPU:
  ```bash
  # Для NVIDIA
  nvidia-smi
  ```

### "ModuleNotFoundError: No module named 'PyQt5'"

**Решение**:
```bash
pip install PyQt5 requests
```

### Приложение зависает при генерации

**Причина**: Нормальное поведение - генерация идёт в фоне

**Что делать**: Просто подождите. Первая генерация может занять до минуты.

## 💡 Советы по использованию

1. **Детализируйте лор** - чем подробнее описание мира, тем лучше контекст для AI
2. **Описывайте стиль речи персонажей** - AI будет точнее имитировать манеру говорить
3. **Используйте контекст диалогов** - включите в настройках для связных разговоров
4. **Экспериментируйте с темами и стилями** - разные комбинации дают разные результаты
5. **Редактируйте результаты** - AI даёт основу, вы её улучшаете
6. **Сохраняйте регулярно** - хотя автосохранение работает при нажатии "Сохранить"

## 🚀 Продвинутое использование

### Использование других моделей

```bash
# Модель для кода и логики
ollama pull codellama

# Специализированная на диалогах
ollama pull neural-chat

# Большая качественная модель (требует >16GB RAM)
ollama pull llama2:70b
```

### Настройка глобального стиля

В настройках в поле "Общий стиль генерации" можно указать:

```
Отвечай всегда на русском языке. Используй псевдосредневековый 
стиль с высокопарной речью. Избегай современных слов и сленга. 
Добавляй атмосферу средневекового фэнтези.
```

### Экспорт данных

База данных находится в `data/dinov_ai.db`. Для резервной копии:
```bash
cp data/dinov_ai.db ~/backup/dinov_$(date +%Y%m%d).db
```
