## 🚀 Запуск приложения

### Предварительные требования

1. **Ollama должен быть установлен и запущен:**
   ```bash
   # Установите Ollama: https://ollama.ai
   # Скачайте модель:
   ollama pull deepseek-v3.1:671b-cloud
   
   # Запустите Ollama:
   ollama serve
   ```

2. **Запустите приложение:**
   ```bash
   ./aihelper
   ```

## 🔧 Сборка проекта

Если нужно пересобрать:

```bash
go build -o aihelper ./cmd/aihelper
```

Для Windows (кросс-компиляция):
```bash
GOOS=windows GOARCH=amd64 go build -o aihelper.exe ./cmd/aihelper
```

## 📚 Основные возможности

1. **Быстрый редактор** (Alt+W) - преобразование текста по стилю
2. **Главное меню** (Alt+F) - доступ ко всем функциям
3. **Менеджер стилей** - создание стилей текста
4. **База персонажей** - управление персонажами
5. **Генератор квестов** - создание квестов через ИИ
6. **Редактор книг** - работа с текстами
7. **Чат-редактор** - работа с длинными текстами
8. **Ролевая игра** - общение с ИИ-персонажами

## 💾 Данные

Все базы данных сохраняются локально в:
- **Windows:** `%APPDATA%/AIHelper/data/`
- **Linux/Mac:** `~/.config/AIHelper/`

## ❓ Проблемы?

1. **Нет главного файла?** → Он в `cmd/aihelper/main.go`
2. **Не собирается?** → Убедитесь, что установлены `pkg-config`, `libgl1-mesa-dev`, `xorg-dev`
3. **Ollama не работает?** → Проверьте, что `ollama serve` запущен и модель загружена
