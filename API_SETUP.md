# Где указать API ИИ в Dinov AI Tools

## 📍 Краткий ответ

API указывается **в приложении**, во вкладке **"Настройки"** (последняя вкладка справа).

## 🎯 Пошаговая инструкция

### Шаг 1: Запустите приложение

```bash
python main.py
```

### Шаг 2: Откройте вкладку "Настройки"

В верхней части окна есть 5 вкладок:
1. Лор
2. Персонажи
3. Квесты и события
4. Диалоги
5. **Настройки** ← откройте эту

### Шаг 3: Настройте подключение

В форме настроек вы увидите поля:

#### 1. **Ollama API URL**
```
http://localhost:11434
```
Это адрес, где работает Ollama. По умолчанию - локально на порту 11434.

**Если Ollama на другом компьютере:**
```
http://192.168.1.100:11434
```
(замените IP на адрес вашего сервера)

#### 2. **Модель**
Выберите модель из выпадающего списка или введите название вручную.

Примеры:
- `llama2` - базовая модель
- `mistral` - более качественная
- `saiga` - для русского языка

#### 3. **Обновить список моделей**
Нажмите эту кнопку, чтобы получить список всех загруженных в Ollama моделей.

#### 4. **Общий стиль генерации** (необязательно)
Здесь можно указать, как именно должна отвечать нейросеть. Например:
```
Отвечай всегда на русском языке. Используй псевдосредневековый 
стиль с высокопарной речью. Избегай современных слов.
```

#### 5. **Сохранять контекст диалогов**
Галочка - если нужно, чтобы AI помнила предыдущие реплики в диалоге.

### Шаг 4: Сохраните

Нажмите кнопку **"Сохранить настройки"** внизу формы.

## 🔧 Файловый способ (для продвинутых)

Настройки хранятся в базе данных `data/dinov_ai.db`.

Можно изменить напрямую через SQL:

```bash
sqlite3 data/dinov_ai.db

# Посмотреть текущие настройки
SELECT * FROM settings;

# Изменить URL
UPDATE settings SET value = 'http://192.168.1.100:11434' WHERE key = 'ollama_url';

# Изменить модель
UPDATE settings SET value = 'mistral' WHERE key = 'model';

# Выйти
.quit
```

## 🌐 Использование удалённого Ollama

### На удалённом сервере:

1. Запустите Ollama с привязкой к внешнему интерфейсу:
```bash
OLLAMA_HOST=0.0.0.0:11434 ollama serve
```

2. Убедитесь, что порт открыт в файрволе:
```bash
sudo ufw allow 11434/tcp
```

### В приложении:

В настройках укажите:
```
http://IP_СЕРВЕРА:11434
```

Например:
```
http://192.168.1.100:11434
```

## 🐳 Использование Ollama в Docker

### Запуск контейнера:

```bash
docker run -d \
  -v ollama:/root/.ollama \
  -p 11434:11434 \
  --name ollama \
  ollama/ollama

# Загрузка модели
docker exec ollama ollama pull llama2
```

### В приложении:

URL остаётся стандартным:
```
http://localhost:11434
```

## ☁️ Можно ли использовать OpenAI / Claude / другие API?

**Короткий ответ**: Нет, приложение работает только с Ollama.

**Длинный ответ**: Технически можно модифицировать код:

1. Откройте файл `modules/ollama_client.py`
2. Измените методы `generate()` и `chat()` под нужный API
3. Адаптируйте формат запросов и ответов

**Или**: Создайте issue с просьбой добавить поддержку другого API.

## 🔍 Проверка подключения

### Вариант 1: Через приложение

1. Откройте "Настройки"
2. Нажмите "Обновить список моделей"
3. Если модели появились - всё работает! ✅

### Вариант 2: Через скрипт

```bash
python check_ollama.py
```

Скрипт проверит:
- Доступность Ollama
- Наличие моделей
- Работу генерации

### Вариант 3: Вручную через curl

```bash
# Проверка, что Ollama работает
curl http://localhost:11434/

# Список моделей
curl http://localhost:11434/api/tags

# Тестовая генерация
curl http://localhost:11434/api/generate -d '{
  "model": "llama2",
  "prompt": "Say hello",
  "stream": false
}'
```

## ❓ Частые вопросы

### "Где вводить API ключ?"

Ollama не требует API ключей при локальной работе. Ключи нужны только для облачных сервисов (OpenAI и т.д.), которые приложение не поддерживает.

### "Где найти API URL?"

По умолчанию: `http://localhost:11434`

Чтобы узнать точный адрес:
```bash
# Посмотрите, на каком порту работает Ollama
ps aux | grep ollama
netstat -tulpn | grep ollama
```

### "Работает ли через VPN / прокси?"

Да, если Ollama доступна по указанному URL. Проверьте через curl.

### "Нужен ли интернет?"

Нет! Ollama работает полностью локально. Интернет нужен только для:
1. Установки Ollama
2. Загрузки моделей

После этого всё работает оффлайн.
