### 🎯 Самый простой способ:
Откройте папку проекта и дважды кликните:
```

```

## 🎯 Как пользоваться

### GUI (графический интерфейс)

1. Запустите `start_gui.bat`
2. В окне появятся 3 вкладки:
   - **🎯 Prompt** - основная панель для команд
   - **📋 Logs** - журнал действий
   - **⚙️ Settings** - настройки

**В панели Prompt:**
- В поле "Search" можно искать шаблоны команд
- В "Context" вставьте текст для обработки
- В "Prompt" напишите, что делать (например: "Переведи на английский")
- Нажмите **"Run Prompt"**

**Горячие клавиши:**
- `Ctrl + P` - открыть панель команд
- `Ctrl + E` - обработать выделенный текст

### CLI (командная строка)

**Интерактивный режим:**
```bash
python agent\cli_app.py interactive
```
Потом вводите команды:
```
Prompt> Переведи "Hello" на русский
Prompt> Создай папку Test на рабочем столе
Prompt> exit
```

**Разовая команда:**
```bash
python agent\cli_app.py run "Открой YouTube"
```

**Со стримингом (потоковый вывод):**
```bash
python agent\cli_app.py run --stream "Расскажи историю"
```

**Посмотреть информацию о системе:**
```bash
python agent\cli_app.py info
```

**История команд:**
```bash
python agent\cli_app.py history
```

## ❓ Если что-то не работает

### 1. Убедитесь, что Ollama запущена:
```bash
curl http://127.0.0.1:11434/api/tags
```

### 2. Проверьте, что модель доступна:
```bash
ollama list
```
Должна быть строка с `gpt-oss:120b-cloud`

### 3. Если модели нет, загрузите:
```bash
ollama pull gpt-oss:120b-cloud
```

### 4. Проверьте логи:
Откройте: `%LOCALAPPDATA%\WindowsAIAgent\logs\agent.log`

### 5. Сбросьте конфигурацию:
Удалите файл: `%LOCALAPPDATA%\WindowsAIAgent\config.yaml`
При следующем запуске создастся новый.
